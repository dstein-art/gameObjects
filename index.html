Make games with real physics in p5.js

GameObjects gives your p5.js sketch boxes, balls and pictures that fall, bounce, stack and collide by themselves. You decide what happens when they touch.

Get started → Play the examples
p5.js 2.x & 1.x Built on Matter.js MIT licensed Made for students 
let player;

function setup() {
  createCanvas(640, 360);

  // a floor that never moves
  new GameObject(320, 350, 640, 20, { isStatic: true });

  // a player that falls onto it
  player = new GameObject(100, 100, 40);
}

function draw() {
  background(220);
  if (keyIsDown(RIGHT_ARROW)) player.velocityX = 5;
  // GameObjects moves and draws everything for you
}

Add it to your sketch

Three extra lines in your index.html, then you're ready.

  1. Download gameobjects.js and put it next to your sketch.js. In the p5.js Web Editor, upload it to your sketch.
  2. Load the scripts in this order in your index.html: p5.js, then Matter.js, then GameObjects.
  3. Start making GameObjects in setup().
